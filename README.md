# simple-status

A small, free-to-host status page with an admin UI and a REST API, running on
Cloudflare Workers and D1. It replaces Server Status v2 and is **not** backwards
compatible with it.

> Work in progress. See [docs/plan.md](docs/plan.md) for the milestones.

## Stack

TypeScript, [Hono](https://hono.dev), Cloudflare Workers + D1, Drizzle, zod,
Vitest (running inside `workerd` via `@cloudflare/vitest-plugin`), Wrangler.

## Development

Requires Node.js 26 (see `.nvmrc`).

```sh
npm ci
npm run dev      # wrangler dev on http://localhost:8787
npm run check    # typecheck, lint, format check, tests
```

`worker-configuration.d.ts` is generated by `npm run cf-typegen` (also run by
`npm run typecheck`) and is not committed. Re-run it after changing
`wrangler.jsonc`.

## Deploying

```sh
npx wrangler login
npm run deploy
```

Deploy from your own machine or CI, not from the devcontainer sandbox. Its
firewall blocks the Cloudflare API on purpose, and it should never hold a
Cloudflare token.
